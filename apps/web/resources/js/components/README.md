# Saffna Web Components

This area owns native JavaScript Web Components. Project-authored component filenames start with `Saffna`. Components call approved HTTP APIs and never access storage directly.

Read the [application architecture](../../../../../artifacts/architecture-decisions/saffna-application-architecture.md) and [web interface baseline](../../../../../artifacts/design-language/web-app/saffna-interface-baseline.md) before adding browser behavior.
