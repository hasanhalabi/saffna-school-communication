# Contributing to Saffna

You are welcome to fork and adapt Saffna. Issues and pull requests that make the course project clearer, safer, or more useful are welcome for review; sending a pull request does not guarantee that it will be merged.

## Licensing

By submitting original work to this repository, you agree to make that contribution available under the repository’s [0BSD license](LICENSE). Do not submit material you cannot license this way. If a change includes third-party material, identify its source and license in the pull request so its terms and notices can be reviewed and recorded in [Third-Party Notices](THIRD_PARTY_NOTICES.md). No contributor license agreement is required for this project.

## A useful pull request

- Explain the problem, the proposed change, and how you checked it.
- Keep the change within the current approved product scope, or open an issue to discuss a new requirement first.
- Use fictional examples. Never include credentials or real school, parent, teacher, or student data.
- Update the relevant documentation when behavior or a decision changes.

This is an educational project under active development. The current repository checkpoint and its limits are described in the [README](README.md).
