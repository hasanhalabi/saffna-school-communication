# Saffna Artifact Templates

These reusable structures are not canonical rules. Copy a template into the correct active artifact folder only within a named approved stage, replace its instructional text with Saffna-specific evidence, and record status, owner, date, source, approval/task provenance, and cross-surface impact. Keep one H1 in the completed document. Read `artifacts/README.md` and the terminology library before authoring.

- `architecture-decision.md`: durable technical choice and supersession.
- `business-rule.md`: product behavior, requirement IDs, validation, and acceptance.
- `integration-contract.md`: versioned inbound or outbound boundary contract.
