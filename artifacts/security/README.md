# Saffna Security And Privacy

This folder governs authentication, authorization, student and family data, privacy, secrets, threats, audit, and retention. The [access baseline](saffna-access-baseline.md) records the four stated login actor types without inventing permissions. The web application will handle school-related personal data, so implementation stages need explicit data classification and protective rules before schemas or accounts are built.

Never store credentials, tokens, private keys, purchase codes, or real student records in repository artifacts, task comments, screenshots, or logs. Document configuration names and approved secret-store ownership only when decided.
