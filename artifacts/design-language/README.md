# Saffna Design Language

This folder owns the platform's visual, interaction, responsive, accessibility, copy, and localization rules. The current web-specific baseline is in [`web-app/saffna-interface-baseline.md`](web-app/saffna-interface-baseline.md). Product behavior remains in business rules; UI rules must not redefine role permissions or module workflows.

Arabic is the primary language and uses RTL layout. English uses LTR layout. Browser support, accessibility acceptance, breakpoints, design tokens, copy review, and translation workflow need later decisions before implementation.
