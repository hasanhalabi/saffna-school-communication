# Saffna Artifact Index

This index routes each concern to one canonical home. Read it before creating, moving, or linking an artifact. Runtime source stays in `apps/web/`.

| Folder | Canonical concern |
| --- | --- |
| `workspace-governance/` | Project profile, structure, terminology, stage approval, and ClickUp rules |
| `business-rules-requirements/` | Current product behavior and acceptance rules |
| `architecture-decisions/` | Durable technical decisions and supersession |
| `design-language/` | Web UI, Arabic/English, responsive, accessibility, visual and copy rules |
| `database/` | Data model, ownership, reviewed migration specifications, retention and recovery |
| `integrations-inbound/` | Contracts for requests or events entering the Saffna platform boundary |
| `integrations-outbound/` | Contracts for calls or events leaving the Saffna platform boundary |
| `security/` | Identity, permissions, privacy, secrets, threats, and audit rules |
| `deployment-operations/` | Environments, release, QA, observation, recovery, and support |
| `templates/` | Reusable noncanonical document structures |
| `product-owner-inputs/` | Dated raw input, preserved but noncanonical |
| `archive/` | Superseded historical content, noncanonical |

The current baseline documents distinguish direct product-owner statements from later decisions. Approval of the foundation stage does not approve unfilled feature workflows. Do not create a local backlog; the configured ClickUp list is the task source of truth.
