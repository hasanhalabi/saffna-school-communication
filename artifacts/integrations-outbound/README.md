# Saffna Outbound Integration Contracts

An outbound interaction leaves the Saffna platform boundary for another system or service. No outbound provider, webhook, email/SMS service, or external API has been approved. The Messaging module name does not imply a particular delivery channel or vendor.

Add a contract here only after the target, data, trust boundary, authentication, failure recovery, and environment are approved. Keep credentials and private endpoint values outside the repository. Do not create speculative integration files or services.
